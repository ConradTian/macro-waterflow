# 历史盲测 (blind backtest mode): contract (2026-10-29)

Approved by the user via the Ray-Dalio-Framework session (part E). It is a separate mode at `/blind/`, not mixed with the course or the simulator.
House rules: the "House rules for everyone" section of `tools/B1B2-CONTRACT.md`.

## Game
- **Card** = country + year, both shown. The player stands at the END of that year.
- **The screen shows:**
  - the water diagram with LEVELS only, because annual data has no flows;
  - both cycle dials, computed **only from data up to that year**;
  - the GDP gap from trend;
  - 相对历史位置: the own-history percentile, up to that year, of credit/GDP, house price/income, equity valuation and the real rate.
- **The player:**
  1. judges the long-cycle stage (①–⑧, B1/B2) and the short-cycle phase (扩张 / 过热 / 收紧 / 降息);
  2. allocates 100 万 AUD in 10% steps across 现金, 国债, 股票, 房子 (the card's home country) and 外币现金 (USD / JPY / CNY / AUD, each earning that country's bill rate).
- **Reveal:**
  - the 1y and 3y real returns of each asset, converted to AUD and deflated by AU CPI;
  - one line on what happened;
  - what the framework would have called, with the signals that were lit.
- **Two scores:**
  - **判断分**: the player's position against the framework's rule-based call. Say plainly that the framework is not ground truth.
  - **收益分**: the player's return against the benchmark, the home country's 60% equities / 40% government bonds, also AUD-real.
- **Every 10 cards:** a bias profile, e.g. 「总是太早买国债」, 「房价横盘时仍以为会涨」.
- **Labels:** cards that use 2021+ data are marked 保留样本. Note survivorship once: only rich survivor countries are in the deck.
- **No gold in v1**, because JST has none.
