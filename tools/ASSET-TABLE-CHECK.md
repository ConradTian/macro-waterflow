# L8 资产反应表 · 美国真实数据核对（1995–2025）

对象：`src/data/lesson-investor.js` 的 `ASSET_ROWS`（现金 / 长期国债 / 股票 / 房产 / 黄金五列；本币列不在本次范围）。
脚本：`tools/b6_dump.mjs`（导出真实数据时间线）→ `tools/b6_check.py`、`tools/b6_extra.py`（统计）。没有下载新数据。

## 方法

- **每季归哪一行**：用 `realTimeline('USA')`（`src/data/real/real-snapshot.js`，和模型同一套 `advanceCycles`）的大小周期表盘，
  再按 `src/ui/investor-lab.js` 的 `nowRow()` 原样映射（⑤/B2 岔路 → b2；⑥ → l6；⑦ → l7，叠 B1 也算 l7；否则小周期降息 → cut，收紧 / 物价过热 → b1）。
  - A 行：美国 1995–2025 没有一季被判为「失去信心」，无样本。
  - C 行：引擎没有这个状态。用 1995Q1–1999Q3 表盘读「扩张」的季度当代理（90 年代后期生产率繁荣），只能参考。
- **之后 4 个季度的实际收益**（全部扣 CPI，`cpiIndex`）：现金 = 政策利率逐季复利；长期国债 = 10 年期平价债持有一年（票息 + 按一年后收益率重估的 9 年期价格）；
  股票 = 标普 500 价格指数（不含分红，分红每年约 +1.5–2%）；房产 = Case-Shiller 全国指数；黄金 = 美元金价。
- **方向怎么算命中**：⬆ = 实际 > 0；⬇ = 实际 < 0；⬆⬆ / ⬇⬇ = 超过 ±5%（股票、黄金 ±10%，现金 ±1%）；— = 在 ±带宽内（现金 1%，国债、房产 3%，股票、黄金 5%）；
  ⬇/— = 实际 < +5%；慢升 = 0 到 +3%；「名义⬆」看名义收益；「⬇（实际）」看实际收益。
- **判定**：对 = 命中率 ≥ 2/3 且中位数本身也符合；错 = 命中率 < 40% 且中位数不符合；其余为部分对；n < 4 记「样本太少」。少数格人工改判，见备注。
- 注意：相邻季度的 4 季窗口互相重叠，真正独立的只有「段」数（表头写了），n 看起来比实际信息量大。
- 2022+ 单列：起点在 2022Q1–2025Q3（需要之后 4 季的真实数据，最晚到 2026Q3）。

## 小结

- **站得住的格**：B1 现金⬆、股票⬇/—；降息 国债⬆、房产⬆；B2 黄金⬆、房产⬇⬇；⑥ 现金⬇、股票⬆；⑦ 股票名义⬆、黄金⬆⬆；C 股票⬆。
- **系统性的错**：黄金的「—」在 B1、降息、C 三行全错。美国这 30 年金价走势和加息 / 降息没有稳定关系（2005–07 加息中大涨，1995–99 下跌），更像跟着实际利率趋势和美元走。建议把「—」改成「看实际利率」或「不定」。
- **B1 国债⬇** 只在 2022 这一次成立；1999–2000 和 2004–07 两段加息里，10 年期收益率早已不再随政策利率上升，持有一年反而赚 +4%。可以写成「加息前半段⬇，后半段转⬆」。
- **B2 行的现金⬆、股票⬇错**，主因是表盘确认 B2 的时间（2008Q3 起，连续 3 季才确认）偏晚：从确认那一季起算，之后 4 季多半已经是 2009 年的反弹。表本身描述的是缩水当中，不是确认之后。
- **⑦ 现金⬇⬇** 在 2022–25 的美国不成立：2023 起政策利率高于通胀，现金实际是正收益。表盘把 2022Q3 起判为 ⑦，但美国这段更像「加息 + 债务高」，不是压着利率的金融压制。
- **降息 一行的两个时间说法**：国债「最先」部分成立（比股票早，但房价在 2001–03 一开始就在涨）；房产「滞后」不成立。
- **⑥ 房产「慢升」**：方向对，但 2012–21 实际房价每年涨约 4%，不算慢。
- A 行没有美国样本；C 行没有引擎定义，只用 90 年代后期做了代理。
- 样本很少：B1、降息、B2 各只有 1–3 段，⑦ 只有一段，判定只能当方向参考。
